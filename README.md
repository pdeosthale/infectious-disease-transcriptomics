# Infectious Disease Transcriptomics

Computational analysis of host immune responses to respiratory infections using public transcriptomic datasets. This project serves as a learning portfolio for computational biology skills applied to infectious disease immunology.

## Dataset

GSE161731: Blood transcriptomics from 198 patients with COVID-19, Influenza, other coronaviruses, bacterial infections, and healthy controls. Published in Nature Communications.

- 60,675 genes, 198 samples
- Raw counts from RNA-seq
- After QC: removed 2 low-quality samples (low library size and gene detection)

## Notebooks

1. 01_python_foundations.ipynb - Python basics with simulated expression data
2. 02_python_programming.ipynb - Functions, loops, file I/O, pairwise fold change analysis
3. 03_numpy_and_data_wrangling.ipynb - NumPy, z-scores, correlation, PCA from scratch
4. 04_real_geo_data.ipynb - GEO data download, metadata exploration, QC, outlier detection, PCA

## Tools

Python, NumPy, pandas, matplotlib, seaborn, scikit-learn, GEOparse
